# azure-flexible-server-postgresql

Owns a PostgreSQL Flexible Server, its configuration parameters, firewall rules and generated administrator password.

Terms below are specific to this module. Cross-cutting vocabulary (Firestartr, ghaps,
`config`, CR, module contract, state boundary, composite module) lives in the root
[`CONTEXT.md`](../../CONTEXT.md); [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) lists the
other contexts.

## Language

**administrator password**:
Generated by the module with `random_password` and stored as a Key Vault secret under `administrator_password_key_vault_secret_name`. It is never an input and never an output.

**Key Vault lookup**:
The Key Vault is found either by `name` + `resource_group_name` or by `tags` through `azurerm_resources`. The tag form exists so callers need not know the vault's name.

**private access**:
The mode where `public_network_access_enabled` is false and the server is placed in `subnet_name` with `dns_private_zone_name`. Switching between private and public access replaces the server.

**server configuration**:
A `postgresql_flexible_server_configuration` entry — one PostgreSQL server parameter. Some parameters require a restart, which Azure performs on apply.
