# Maintained Static Option Lists

The module validates engine versions and regions against separate allowlists, and validates plan-specific flavors and disk range/increment from a maintained snapshot in `data/postgresql-offers.json`, sourced from OVHcloud's authenticated availability catalogue. It deliberately does not validate whether those dimensions form a jointly available offer or whether an offer is currently available to the caller's project; selecting a valid combination is the module consumer's responsibility, and OVHcloud remains authoritative at apply. The module is limited to stable private-network offers and resolves the caller's existing network and subnet separately. This avoids a runtime API helper and its Python, provider and authentication requirements. The trade-off is that the snapshot is point-in-time and project-scoped. Refresh and review the full offer snapshot when availability changes.
