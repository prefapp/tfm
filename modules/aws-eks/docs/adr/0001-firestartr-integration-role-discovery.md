# Discover Firestartr integration roles by name and tags

The module identifies the customer roles `FirestartrBackstageReader` and `FirestartrArgoCDAdmin` by exact role name, then verifies their `FirestartrIntegration`, `ManagedBy=Prefapp`, and `ProvisionedBy=CloudFormation` tags before creating EKS access entries. These defaults are intended for integration with [Firestartr](https://docs.firestartr.dev/docs/). Consumers can override each role name and its non-empty required-tag map for another naming/tagging convention. AWS provider role discovery supports name filtering but not a direct tag query; requiring exactly one correctly tagged result prevents ambiguous or unrelated roles from receiving cluster access.
