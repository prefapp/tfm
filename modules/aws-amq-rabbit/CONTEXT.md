# aws-amq-rabbit

Owns one Amazon MQ RabbitMQ broker and, depending on the access mode, the network load balancer that fronts it.

Terms below are specific to this module. Cross-cutting vocabulary (Firestartr, ghaps,
`config`, CR, module contract, state boundary, composite module) lives in the root
[`CONTEXT.md`](../../CONTEXT.md); [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md) lists the
other contexts.

## Language

**broker**:
The single `aws_mq_broker` RabbitMQ instance this module owns. Named from `project_name` and `environment`.

**access mode**:
One of `public`, `private` or `private_with_nlb`. It decides whether consumers reach the broker directly or through the module's NLB; `private_with_nlb` is the only mode that requires `lb_certificate_arn`.
_Avoid_: exposure, visibility

**exposed port**:
A broker port opened on the security group and, under `private_with_nlb`, given its own NLB listener and target group. Defaults to AMQPS (5671) only.

**deployment mode**:
`SINGLE_INSTANCE` or `CLUSTER_MULTI_AZ` — the broker's redundancy shape, distinct from *access mode*.

**subnet discovery**:
The rule that explicit `*_subnet_ids` win, and `*_subnet_filter_tags` are used only when they are absent. The same precedence applies to `vpc_id` over `vpc_name`.

**broker password**:
Generated by the module with `random_password` and written to SSM Parameter Store. It is never an input and never an output value in clear text.
