# Application users remain outside the service module

The service module does not create database users or publish user credentials. OVHcloud's API-created MySQL users receive administrator-equivalent grants, while least-privilege application users must be created with SQL and cannot be managed through the OVHcloud API. Putting those API users into application secrets would violate least privilege; embedding SQL-user management here would also require a separately staged provider connection whose endpoint and bootstrap credentials only exist after service creation. The service module therefore owns only the MySQL service and databases. A future user-provisioning module can manage SQL accounts in a separately configured lifecycle. See [OVHcloud's MySQL user guidance](https://docs.ovhcloud.com/en/guides/public-cloud/databases/mysql-prepare-for-incoming-connections/#step-1-verify-your-users-and-password).
