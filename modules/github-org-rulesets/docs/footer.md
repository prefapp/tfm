## Examples

For detailed examples, refer to the [module examples](https://github.com/prefapp/tfm/tree/main/modules/github-org-rulesets/_examples):

- [basic](https://github.com/prefapp/tfm/tree/main/modules/github-org-rulesets/_examples/basic) - Org-wide default branch protection targeting repositories by name, with a CI status check and a numeric bypass actor (`config.json`)
- [advanced](https://github.com/prefapp/tfm/tree/main/modules/github-org-rulesets/_examples/advanced) - Multiple rulesets using the full GitHub API export format, including repository custom property targeting, a bypass actor by repository role, a push ruleset, required_reviewers, and copilot_code_review (`config.json`)
